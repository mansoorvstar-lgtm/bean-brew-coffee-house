Bean & Brew Coffee House - HTML/CSS Website

Files:
- index.html : Home page
- about.html : About page
- menu.html : Menu page
- css/style.css : Website styling
- images/coffee-shop.jpg : Optional hero image

To add your own image:
1. Put a coffee-shop image inside the images folder.
2. Name it coffee-shop.jpg
3. Open index.html in a browser.

The website uses HTML and CSS only. No JavaScript is included.
